# Impulse-X — Rocket Tec

Landing estática para el equipo de cohetería Impulse-X. Está lista para publicarse en GitHub Pages.

## Publicación

1. Crea un repositorio público llamado `F1025_503` en la cuenta `DENZJG08`.
2. Sube el contenido de esta carpeta a la rama `main`.
3. En el repositorio, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**, elige `main` y la carpeta `/(root)`; guarda los cambios.
5. GitHub publicará el sitio en `https://denzjg08.github.io/F1025_503/` tras unos minutos.

El logo se encuentra en `assets/impulse-x-logo.png`. La portada no tiene dependencias de construcción ni contenido de terceros, salvo la carga opcional de las tipografías desde Google Fonts.
